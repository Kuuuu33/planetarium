# 🔭 プラネタリウム / Planetarium

ブラウザで動く、実際の星空を再現するプラネタリウム。
主要な星・星座・天の川を正確に配置し、流れ星やヒーリング音楽の演出も。
スマホ・PC・プロジェクター投影に対応。

## 公開ページ

https://kuuuu33.github.io/planetarium/

制作物一覧: https://kuuuu33.github.io/

## 使い方
- 画面をタップ / マウス移動でコントロールパネルが出ます（数秒で自動的に隠れます）
- 場所・日時の速さ・星の明るさを調整できます
- 「🎵 音楽を再生」でヒーリング音楽（自動生成アンビエント）が流れます
- `F` キー / 「全画面で投影」ボタンで全画面（iPhone は「ホーム画面に追加」で全画面起動）

単一の HTML ファイルで完結しています（外部依存なし）。

## 保存データについて

この作品は localStorage 等を **一切使っていません**（設定は保存されず、リロードで初期値に戻ります）。

今後もし保存機能を足す場合は、キー名を必ず `planetarium-` で始めてください。
`kuuuu33.github.io` 配下の作品はすべて同じオリジンで保存領域を共有しており、
接頭辞がないと他の作品のセーブデータを壊します。
詳細は [まとめサイトの README](https://github.com/kuuuu33/kuuuu33.github.io#-新しい作品を作るときのルール保存キーに接頭辞をつける) を参照。
